- A selected source with zero events in the discovery window now costs only its volume search. The run measures and activates the sources that have events, leaves the quiet source's earlier records unchanged, and fails without activation only when every source is quiet. A source with events whose field listing is empty fails the run with its own reason.
- Inventory runs record each zero in `quiet_source_ids`. A source that was quiet in its latest run stays pending, earns no value or pending-work credit from it, and status shows the zero, its window, other types seen in that repository in saved scout and refresh captures, and an optional type listing the agent may run itself.
- The capture hook no longer queues a new source for a search that names only the repository of a confirmed typed source.
