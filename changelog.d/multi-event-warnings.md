- `check` warns with `CQL_JOIN_MAX` when a `join` without `max` includes a field that a later filter or `test()` compares with `<`, `<=`, `>` or `>=`, as a time-window test does: `join` keeps one matching subquery row per key unless `max` is set, so the comparison tests only that row. A subquery that ends in a `groupBy` on join keys only is not reported. `CQL_UNEXPORTED_FIELD` names a field that a correlate does not export and the named query it was expected from; before, this appeared only in `grounding.basis` as "not exported by preceding query". With `--require-observed` the field stays in `grounding.missing` instead of a warning.
