- `setup` accepts `registration: {"mode":"host-managed"}` for Codex, VS Code Local, Claude Code and the Copilot clients, not only for `external`: setup uses the MCP server already configured in that client, runs no client command, changes nothing in its configuration and verifies only the saved tool-discovery report, which may then omit `effective_oauth_client_id` and `effective_config_source`. 0.1.13 refused this with `SETUP_REGISTRATION_MODE`, so a Codex server that setup had not added could not be used by any route. 0.1.13 and earlier refuse a saved state that holds such a selection.
- With `host-managed`, `select` reports matching servers in readable client configuration and names skipped files. It identifies disabled, invalid or potentially overridden names for inspection. The wizard suggests usable aliases where inspection is complete. A native preview that would add a server or refuses a collision can recommend usable aliases. When Codex registration cannot be confirmed, setup advises using `host-managed` with the selected server name.
- Submitting the current selection again keeps its configuration assertion and imported report. 0.1.13 returned to `selected`, and importing the same report then failed with `SETUP_NOT_CONFIGURED`. A changed selection still clears them.
- Setup reads client MCP files that contain comments or trailing commas, so VS Code Local no longer stops with `SETUP_NATIVE_CONFIG` when its server is already configured. Preview still refuses such a file when the plan would have VS Code or Claude Code add the server and so rewrite the file. A preview that writes nothing no longer mentions an original-config backup.
- `SETUP_DISCOVERY_BINDING` names the report field that does not match the selection (`schema_version`, `client`, `host_id`, `server_name`, `endpoint` or `authenticated`), or the tool count, without repeating the supplied value. `SETUP_CAPABILITY` for the CIMD flow names a registration the client accepts: `host-managed` for Claude Code, manual registration for VS Code Local and Codex. Refusing manual registration for Claude Code now also names `host-managed`. Guidance for an `external` host names its `host_id` in place of "Other agent".
