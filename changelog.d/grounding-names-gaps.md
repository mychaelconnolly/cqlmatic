- With an environment map, `check` and `generate` warn about what the map lacks. `CQL_UNMAPPED_SOURCE` reports a `#repo` or `#type` value that matches no mapped source, names mapped selectors, and says when the value is the target view's name. `CQL_UNMAPPED_FIELD` reports a field that no selected source lists as observed or documented, naming those sources. A field listed only as documented, a field the query produces and `@` metadata fields are not reported. `CQL_GROUNDING_LENIENT` is removed: 0.1.10 emitted it, with or without a map, for any query reading a field without qualifying observed evidence, so `--fail-on-warning` exited 1 for such queries. `grounding.basis` keeps the evidence for each field, and `--require-observed` is unchanged.
