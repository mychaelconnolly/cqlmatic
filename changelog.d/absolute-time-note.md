- `check` and `generate` add the informational note `CQL_ABSOLUTE_TIME_FILTER` when a filter or `test()` compares `@timestamp` with a fixed number using `<`, `<=`, `>` or `>=`: the time window belongs in the search request's `start` and `end`, so the query is not tied to one window. `generate` still emits the plan as written. The note does not change `ready`, and `--fail-on-warning` ignores it.
