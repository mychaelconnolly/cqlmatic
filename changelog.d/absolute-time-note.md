- `check` and `generate` add the informational note `CQL_ABSOLUTE_TIME_FILTER` when a top-level filter or `test()` of the main query compares `@timestamp` with a fixed number using `<`, `<=`, `>` or `>=`, on its own or joined by AND, and the query does not set its own window with `setTimeInterval`: the time window belongs in the search request's `start` and `end`, so the query is not tied to one window. `generate` still emits the plan as written. The note does not change `ready`, and `--fail-on-warning` ignores it.
